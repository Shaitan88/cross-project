# Castle Escape

Учебная ретро-игра про побег из замка. Три миссии и 17 комнат. Логика и карты работают на Lua, окно, ввод, звук и отрисовка — на C++17 и SDL2. Пиксельный шрифт Press Start 2P встроен в исполняемый файл. [Лицензия шрифта](assets/fonts/PressStart2P-OFL.txt).

## Управление

- **Enter / Space** — начать игру.
- **WASD / стрелки** — движение и прицеливание.
- **E** — открыть дверь или использовать объект рядом.
- **Space** — выстрел. Шесть патронов на кампанию. Остаток переносится на следующий уровень.
- **P** — пауза и продолжение. Потеря фокуса ставит игру на паузу.
- **R** — начать кампанию заново. **Esc** — выйти.

В первой комнате каждой миссии есть короткий намёк. Янтарная дверь закрыта, зелёная открыта, дверь с навесным замком требует выполнить условие миссии. Ключ золотой, выход мятный, активированный рубильник или пульт становится синим.

## Миссии

1. **Побег** — пять комнат. Доберитесь до ключа через коридор или склад, затем откройте проход к выходу.
2. **Диверсия** — шесть комнат. Отключите два рубильника в любом порядке, вернитесь в центральный узел и откройте выход.
3. **Прорыв** — шесть комнат. Используйте оба пульта шлюзов. Выбирайте между прямыми проходами и обходами через складские помещения.

После обнаружения над охранником появляются три секунды. Устранение охранника до срока отменяет его предупреждение. Иначе включается глобальный таймер на десять секунд. За это время можно закончить миссию. Тревога продолжается при смене комнаты и замораживается на паузе. Охранник в той же комнате слышит выстрел в радиусе 300 пикселей, останавливается и смотрит в сторону стрелявшего. Тревога начинается только после обнаружения игрока и окончания предупреждения. После перехода в другую комнату действует 1,5 секунды защиты от обнаружения и контакта с охраной.

## Сборка

Linux требует CMake, компилятор C++17, SDL2 и Lua 5.4 или новее.

```sh
cmake -S . -B build
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/castle_escape
```

Windows x86 собирается через MinGW-w64. Скрипт запускает тесты под Wine. Артефакт — `dist/windows-x86/castle_escape.exe`. [Зависимости и команды](docs/windows-x86.md).

```sh
./scripts/build_windows_x86.sh
```

WebAssembly собирается через Emscripten. Откройте [страницу игры](http://127.0.0.1:8080/castle_escape.html) после запуска локального сервера.

```sh
./scripts/build_web.sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist/web
```

CTest покрывает свойства движения, переходы и блокировки, боезапас, столкновения пуль, сроки тревоги, цикл приложения и SDL smoke-тест. Тест кампании проходит три миссии с шагом 1/60 секунды в двух вариантах маршрута.

## Тестирование

Модульные тесты проверяют отдельные игровые инварианты. Запускаются так:

```sh
cmake -S . -B build
cmake --build build --parallel
./build/game_logic_test
```

Проверяются покой игрока, скорость фиксированного шага, нормализация диагонали, столкновения со стенами, неверное время, границы комнат и Lua-снимок состояния.

Интеграционные тесты проверяют взаимодействие подсистем. Полный запуск:

```sh
ctest --test-dir build --output-on-failure
```

В него входят проверки дверей и комнат, охраны и укрытий, патронов и предупреждений, трёх миссий, перезапуска, игрового цикла и создания SDL-окна. Отдельный smoke-тест можно запустить так:

```sh
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy ./build/castle_escape --smoke-test
```

Продвинутое тестирование выполнено как property-based тестирование. `game_logic_test` использует фиксированный seed `0xCA57`, генерирует 10 000 случайных направлений и длительностей и после каждого шага проверяет инварианты положения игрока, конечность координат и соблюдение границ. Это делает сбои воспроизводимыми.

Windows x86 запускает тот же набор через Wine:

```sh
./scripts/build_windows_x86.sh
```

WebAssembly собирается отдельно и проверяется загрузкой всех HTML, JavaScript и WASM-ресурсов через локальный HTTP-сервер:

```sh
./scripts/build_web.sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist/web
```
